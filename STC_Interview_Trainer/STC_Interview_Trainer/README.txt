STC INTERVIEW TRAINER
=====================

Lancement
1. Extrais le dossier.
2. Ouvre index.html dans Chrome, Edge ou Firefox.
3. Aucun serveur ni installation n'est nécessaire.

Fonctionnalités
- Tableau de bord et profil de préparation.
- 12 QCM avec correction automatique et explications.
- Filtre par catégorie.
- Questions ouvertes adaptées au parcours communiqué.
- Sauvegarde locale des réponses dans le navigateur.
- Copie de la réponse seule ou du prompt complet à coller dans ChatGPT / Claude.
- Liste de révision des QCM incorrects.
- Réinitialisation de la progression.

Limite importante
Cette version est frontend uniquement. Elle ne contient aucune clé API et n'envoie aucune réponse à une IA.
Pour obtenir une correction IA, utilise le bouton « Copier pour correction IA », puis colle le texte dans ChatGPT ou Claude.

Personnalisation
Les questions et leurs corrections QCM se trouvent dans app.js, dans le tableau quizQuestions.
Les questions ouvertes et conseils se trouvent dans oralQuestions.
Les réponses sauvegardées restent dans le localStorage du navigateur utilisé.
